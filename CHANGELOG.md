# Changelog

## 1.1 (2026-10-25)

- A setup checklist that ticks itself off: move to Applications, allow Accessibility, hide your first icon. Settings now opens by itself only until setup is done.
- On macOS 27, icons of newly installed apps start out visible instead of hidden. Choose under Menu Bar › New icons.
- Optional Check for updates, off by default.
- Shared look with Pervitin: same type, sliding grey and footer.
- Removed: the notch menu and "Use the full menu bar when expanded".
